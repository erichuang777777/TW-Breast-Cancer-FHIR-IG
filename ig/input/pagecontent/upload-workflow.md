# XML 批次上傳流程

{% include disclaimer.md %}

1. 在 VPN「乳癌照護品質提升方案 → 資料上傳作業」選取 XML 後上傳。
2. 上傳後查詢，初始狀態顯示「檢核中」；處理時間依資料量而異。
3. 顯示「系統錯誤」時，代表 XML 上傳格式或資料檢核失敗，可下載檢核錯誤檔。
4. 錯誤檔為加密 ZIP，解鎖密碼為院所登入 VPN 的密碼；不得將密碼寫入 IG、程式碼、日誌或 GitHub。
5. 錯誤明細會列出錯誤筆數、必填 Tag 缺漏及欄位格式不符等結果；修正後重新上傳。
6. 成功時狀態顯示「檢核成功」及成功筆數。

本地 mock receiver 只能模擬 Big5、XML 結構及業務規則檢核，不能視為 VPN 已受理。正式驗收證據應保存上傳檔 SHA-256、上傳時間、VPN 狀態、成功／錯誤筆數與錯誤檔，但不得提交含病人資料或密碼的檔案到公開 repository。
