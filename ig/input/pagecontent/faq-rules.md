# QBC 情境規則

{% include disclaimer.md %}

本頁整理 115 年 6 月 29 日修訂的 QBC 問答集。這些規則不是單一 XML 欄位的格式限制，部分必須由臨床人員、整批資料或健保署核付系統判定。

## 首次復發與第二原發

首次復發須有完成原治療後的無病／緩解期，之後第一次確認為源自原乳癌的局部、區域或遠端復發。若新腫瘤起源不同或符合癌登第二原發準則，應建立新診斷案件，而不是首次復發。

問答集另規定 de novo Stage IV／轉移性乳癌走「首次復發個案」的 VPN 收案路徑，但 `P08` 仍依本院／他院診斷治療填 Class 1 或 2。由於欄位名稱與臨床語意不完全一致，審核時必須標記為 de novo mBC，避免錯認為治療後復發。

## 開刀前短期荷爾蒙用藥

開刀前服用 3 天荷爾蒙藥物，不視為新輔助性（前導性）治療，應以「新診斷個案－直接治癒性手術」登錄，即 `DIAG_TYPE=1`。

這是臨床分類規則。驗證器可以檢查 `DIAG_TYPE=1` 的欄位與治療結構，但僅憑 XML 無法證明用藥目的、療程是否符合臨床指引，因此仍須人工審核病歷與用藥紀錄。

## 雙側乳癌

- 不論左右兩側病理型態是否相同，同一病人都要建立兩筆臨床資料。
- 一筆使用 `LATERALITY=L`，另一筆使用 `LATERALITY=R`；不得使用 `B` 或 `L,R`。
- 若兩側嚴重程度不同，先填報較嚴重側，例如分期較晚或腫瘤較大者，再填另一側。
- 左右側的診斷、TNM、Stage、病理、生物標記、手術及其他患側資料應各自填在對應紀錄。

「是否確實為雙側」及「哪一側較嚴重」需要比較兩側病歷；單筆 XML 無法獨立證明。正式送件前應執行同一 `HOSPID + ID + BIRTHDAY` 的 L/R 配對與排序審核。

## 獎勵核算

雙側雖有兩筆臨床資料，整合照護及追蹤獎勵仍以人為單位，按 `ID` 歸戶。系統以較嚴重患側作為核算基準，不重複給付。

本地驗證器只能提示歸戶規則，無法替代健保署核付系統的實際勾稽結果。

## 同側出現多種組織學分類

同一側乳房若檢驗出兩種以上組織學分類，只填報較嚴重的樣態，不得因此新增第二筆臨床資料。此項須由臨床／病理 reviewer 根據原始病理報告確認。

## 停經狀態

問答集引用的判定情境包括雙側卵巢切除、年齡至少 60 歲、60 歲以下自然停經至少 12 個月，或 60 歲以下使用 tamoxifen／toremifene 者以 FSH 與 estradiol 證實停經。符合者填已停經；無法確定停經年齡時，問答集指示填 60 歲。60 歲以下若因化療或子宮切除而無月經、但沒有生化證據符合停經標準，填未停經。

這項判斷需要病歷、手術史、用藥及檢驗證據，不能只靠 `P05/P06` 自動推論。

## 惡性葉狀瘤分期

惡性葉狀瘤通常參照 AJCC 第八版軟組織肉瘤分期邏輯。VPN 操作方式是 TNM 填未知，待畫面顯示無對應分期後由使用者自行填列。這可能不同於一般乳癌 TNM 自動換算，必須由臨床 reviewer 確認，不可強行套用一般乳癌查表。

## 多院治療與轉介

若部分療程在他院進行、主要治療與追蹤仍由本院負責，該療程的 `TM03` 填他院治療即可，不必轉出。若後續均不在本院治療或追蹤，原院應先完整登錄本院療程，再於追蹤資料填轉出狀態及日期，接續醫院收案後只新增其院內療程與追蹤。

同一個案同一時間只允許一家醫院收案。自行轉院、拒絕在原院治療／追蹤或失聯時，原院依實際狀況辦理轉出或結案。

## 修改與刪除

一般欄位錯誤可修改並重新送出，VPN 保存最新送出資料。整筆刪除限本院自行收案、建檔後 5 日（120 小時）內且尚未轉出／結案；轉出後原院資料不可修改，接續院也只能檢視原院紀錄。

## 審核證據

建議每個相關案件至少保留：左右側病理報告、TNM／Stage、腫瘤大小、登錄順序判斷、同側多型態的取捨理由，以及 ID 歸戶檢查結果。
