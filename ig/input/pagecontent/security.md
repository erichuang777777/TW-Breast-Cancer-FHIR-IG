# 安全與隱私

{% include disclaimer.md %}

QBC 資料可能包含身分證字號、生日、診斷、病理、生物標記及治療資訊，應視為高度敏感健康資料。

## 最低控制

- 公開範例只使用完全合成資料。
- 傳輸與儲存必須加密，並限制最小必要權限。
- 保留存取、修改、人工核准及輸出的稽核軌跡。
- 未經機構授權，不得將可識別資料傳送至外部或 cloud AI 模型。
- 發布流程應拒絕病例檔、runtime 輸出、金鑰、token 與環境設定。
- Provenance 只證明資料來源與處理歷程，不等同資料內容已獲臨床確認。

實作者仍須依其司法管轄、契約、院內政策及實際交換情境完成風險評估。
